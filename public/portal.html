Website analytics

        
See page visits and clicks here, and connect your own Google Analytics tag.

        

          
Tracking settings

          

          


            

          
Find your G- ID in Google Analytics → Admin → Data streams → your website. Google tag IDs starting GT- also work. Separate up to three IDs with commas. GTM containers and older UA IDs are not supported.

          
Visitors choose whether to allow analytics. Google results appear in your Google Analytics account; the dashboard below uses Bitpype's own measurements. If you already installed Google tags manually, remove those before enabling this connection to avoid duplicate measurements.

          
          
After first enabling tracking, use Website → Publish to install it. This does not publish automatically. Settings changes apply on the next page load once the tracker is installed.
